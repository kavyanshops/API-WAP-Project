# API WAP Project - Country Explorer

## Project Idea
A simple web application that helps users explore countries.

Users will be able to:
- Search countries by name
- Filter countries by region (Asia, Europe, Africa, etc.)
- Sort countries by population or name
- View basic country details such as flag, capital, population, and region

This project is beginner-friendly and fits the requirement of using JavaScript, API integration, and UI development.

## Public API
I will use the **REST Countries API**:
- API Website: https://restcountries.com/
- Example endpoint: https://restcountries.com/v3.1/all

This API is public and works well for implementing search, filtering, and sorting.

## Planned Features
1. Fetch country data using `fetch()`
2. Display country cards in the UI
3. Search by country name
4. Filter by region
5. Sort by:
   - Name (A-Z / Z-A)
   - Population (Low to High / High to Low)
6. Responsive and clean CSS layout

## JavaScript Concepts to Be Used
- `fetch()` for API integration
- Array High-Order Functions:
  - `filter()` for search and region filtering
  - `sort()` for sorting by name/population
  - `map()` for rendering country cards

## Technologies
- HTML
- CSS

## Project Structure (Planned)

## Setup and Run
1. Clone the repository:
   ```bash
   git clone https://github.com/kavyanshops/API-WAP-Project.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

No backend or extra installation is required.
